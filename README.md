# Join Markt

**Commerce infrastructure for digital products.**

Join Markt is a commerce platform for creators and teams who sell digital goods. Launch a branded storefront on your domain, accept payments, deliver instantly, and operate everything from one merchant dashboard.

[Website](https://joinmarkt.com) · [Documentation](https://docs.joinmarkt.com) · [System status](https://status.joinmarkt.com)

---

## What we ship

| Surface | Purpose |
| --- | --- |
| **Storefront** | Customer-facing shop on your subdomain or custom domain |
| **Checkout** | Secure payments, wallets, and instant delivery |
| **Dashboard** | Products, orders, customers, coupons, and analytics |
| **Themes** | Visual builder with live preview before you publish |

## For developers

- Merchant API and webhooks for automation
- Checkout links and hosted flows
- Model Context Protocol (MCP) tools for AI-assisted operations
